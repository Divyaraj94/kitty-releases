# Kitty AI Companion (`v1.0.0`)

**Desktop Companion, Instant Voice Typing, and AI Text Enhancer for Windows (x64).**

Kitty lives quietly on your desktop and lets you hold **Caps Lock** to dictate cleanly anywhere, or highlight text and press **F7 / F8 / F9** to fix grammar, engineer prompts, or polish tone across any app.

---

## Download (`v1.0.0`)

- **Windows Installer (Recommended):** [Download `KittySetup.exe`](https://github.com/Divyaraj94/kitty-releases/releases/latest/download/KittySetup.exe)
- **Portable Archive / All Releases:** [Browse Releases](https://github.com/Divyaraj94/kitty-releases/releases)

## Key Features

- **Hold-to-Speak Voice Typing (`Caps Lock` default):** Live 60 FPS soundwave pill, smart cleaning & formatting across English, Hindi, Gujarati, and mixed speech, plus spoken commands (`"new line"`, `"new paragraph"`, `"scratch that"`).
- **AI Text Hotkeys Everywhere (`F7` / `F8` / `F9`):**
  - `F7` **Fix Grammar** — fixes spelling, punctuation, and grammar.
  - `F8` **Prompt Agent** — turns rough notes into structured AI prompts.
  - `F9` **Mix Polish** — rewrites concisely in a crisp, clear tone.
- **App-Aware Tone:** Adapts tone automatically for VS Code, WhatsApp/Slack, Gmail/Outlook, and AI chats.
- **Free Cloud or Private Offline Mode:** Works with free **Groq** / **Gemini** API keys (Voice + Text) or local **Ollama** models (offline Text hotkeys).
- **Dictation Hub & Built-in Update Checker:** Review searchable voice history & WPM stats, and click **`v1.0.0`** in Settings (or Tray → **Check for Updates**) anytime.

## Quick 1-Minute Setup

1. Run **`KittySetup.exe`** (or extract **`Kitty-Portable.zip`** and open `Kitty.exe`).
2. Click Kitty to open **Settings**.
3. Under **Cloud API**, click **Free Key ↗** next to **Groq** or **Gemini**, sign in with Google, paste your key, and click **Save Settings ↗**.
4. *(Optional Offline Mode)* Switch to **Local (Ollama)**, install Ollama, and download a starter model (`qwen2:1.5b`) right inside Kitty.

To exit Kitty anytime: right-click the **Kitty** icon in the Windows System Tray (bottom-right) → **Exit**.
